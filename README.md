# MY_TinyML 🧪

Welcome to my repository for lightweight machine learning experiments, algorithms, and micro-projects. This workspace acts as my hands-on laboratory for exploring feature engineering, testing models, and solving real-world data science challenges step-by-step.

## 📁 Repository Structure

Each subdirectory is a standalone project containing a clean dataset, interactive VS code Jupyter notebooks, and production-ready Python execution scripts.
    

### 🔋 Battery SOC Estimation Model
Machine learning project comparing Linear, Exponential, and Logarithmic regression profiles to map battery capacity. Models are compressed into optimized, low-overhead C/C++ scalar formulas ready for embedded TinyML deployment.

➡️ [View Battery SOC Estimation Model](./Battery_SOC_Estimation/)

   
### 🌡️ Temperature Regression Model

Time-series regression project for temperature prediction using
polynomial regression and feature engineering.

➡️ [View Temperature Regression Model](./Temperature_Regression_Model/)
